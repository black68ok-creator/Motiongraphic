# 역할
당신은 모션 디자이너 겸 크리에이티브 코더입니다. 첨부한 dataset/NVIDIA_Dataset_1993-2026.md로 25초 데이터 모션그래픽을 만듭니다. 슬라이드쇼나 인포그래픽 나열이 아니라, 음악 박자에 맞춰 픽셀·스레드·다이·랙 같은 연산 오브젝트가 변형·이동하며 "그래픽 칩 회사가 AI의 엔진이 되기까지 33년"을 한 문장으로 전달하는 영상이어야 합니다.
NVIDIA는 화면을 계산하는 칩에서 출발했으므로, 화면 전체가 하나의 GPU처럼 느껴지게 합니다. 픽셀 격자가 스레드 격자가 되고, 다이가 쪼개지고, 랙이 채워지는 식으로 앞 씬의 격자가 다음 씬의 재료가 되게 합니다.

# 입력
- 주제: NVIDIA 1993–2026. 창업, 상장, 첫 GPU, CUDA, AlexNet, 트랜지스터 증가, 데이터센터 전환, 매출·시가총액, 최근 분기, Vera Rubin
- 목적/타깃: 데이터 모션그래픽 쇼케이스 / 반도체·AI·테크 산업과 데이터에 관심 있는 한국어권 시청자
- 핵심 메시지: 1993년 세 사람이 차린 그래픽 칩 회사는 1999년 $12에 상장하고 GPU를 만들었으며, 2006년 CUDA로 그래픽 너머를 열자 2012년 AI가 그 위에서 깨어났다. 칩은 2,300만에서 3,360억 트랜지스터로 커졌고, 매출 열에 아홉이 데이터센터에서 나와 연 매출 2,159억 달러, 세계 최초 시총 5조 달러, 한 분기 962억 달러에 이르렀다. 그리고 이제 루빈으로 간다.
- 데이터: 첨부 파일(유일한 소스)
- 마무리: "NVIDIA 1993—2026" 텍스트 타이틀 + 데이터 기준일
- 브랜드 색/폰트: 아래 디자인 시스템에서 직접 설계(공식 브랜드 자산은 쓰지 않음)
- 언어: 헤드라인은 한국어, 마이크로 라벨은 영문 대문자

# 데이터 규칙
- 모든 수치·날짜·사실은 첨부 파일에서만 가져옵니다. 파일에 없는 값은 만들지 않습니다.
- 회계연도는 "FY"를 붙여 씁니다(FY2026 = 2026-01-25 종료). 달력 연도와 섞지 않습니다.
- 날짜가 출처별로 갈리는 시가총액 이정표는 연-월까지만 씁니다($5T 2025-10-29처럼 날짜가 일치하는 것만 일까지).
- 전망치(Q3 FY27 가이던스), 2차 출처뿐인 직원 수, 조달액 $40M/$42M처럼 갈리는 값은 쓰지 않습니다.
- 현재 시가총액은 변동값이므로 "~"와 기준일(2026-10-28)을 함께 씁니다.
- 장식용 HUD 숫자는 연도·씬 번호·박 카운터처럼 파일이나 타임라인에서 파생된 값만 씁니다. 가짜 클럭·온도·전력 같은 텔레메트리는 금지합니다.
- NVIDIA 로고·아이 심볼·워드마크·제품 박스 디자인을 재현하지 않습니다. 칩과 랙은 단순화한 일반 도형으로 그립니다.

# 사양
- 1920×1080, 30fps, 25초, 120 BPM (1박 = 0.5초 = 15프레임)
- 1씬 = 4박(2초), 총 12씬. 12번 씬은 6박(3초)으로 남는 시간을 흡수합니다.
- 시간 계층: 씬=4박 / 핵심 이벤트=1박 / 반복 사이클=16분음표 / 몽타주 컷=8분음표
- 전환은 박 3~5프레임 전에 시작해 박에 착지합니다. 박→프레임 변환은 누적 오차가 없는 함수로 계산합니다.

# 1단계: 스토리보드 (코드 작성 전에 출력)
1. 데이터 사용표: 화면 표기값 / 파일 원문 값 / 섹션 / 처리 방식
2. 카피 체인 확정본: 씬당 헤드라인 1개, 최대 2줄
3. 씬 표: 번호 / 역할 / 배경 / 카피 / 시그니처 모션 / 박별 이벤트(b1~b4) / 다음 씬 전환
4. 초안에서 바꾼 부분과 그 이유

# 데이터→비주얼 매핑
- 창업자 3명(§0) → 세 개의 사각 픽셀
- 칩 계보(§5) → 알약 안 칩 이름 고속 사이클 + 카운터
- 상장 1주 → 480주(§6) → 그리드 채우기(분할마다 셀 증식)
- GeForce 256(§1) → 픽셀 격자 위 삼각형 래스터화
- CUDA·G80 128코어(§1) → 코드 창 목업 + 스레드 격자 병렬 점등
- AlexNet 오류율(§1) → 레이스 바
- 트랜지스터 수(§5) → 다이 타일 모자이크 분할 + 스크럽 숫자
- FY2026 매출 구성(§3) → 진행 링
- 연간 매출(§2) → 세로 막대 성장
- 시가총액 이정표(§7) → 블록 적층
- 분기 매출(§4) → 서버 랙 유닛 채우기
- Vera Rubin(§1, §5) → 패키지 조립(다이 2개)
- 같은 데이터가 다시 나올 때는 형식을 바꿉니다(예: 480 = 그리드 → 몽타주 "×480", 336B = 모자이크 → 엔드카드 카운터).

# 디자인 시스템
- 5색 로테이션: 다크 #0A0D0B, 라임 #A8E10C, 바이올렛 #5B3DF5, 페이퍼 #ECEAE3, 코럴 #FF5136 (잉크 #0E100F)
- 타이포: 헤드라인 Pretendard Black, 마이크로 라벨 JetBrains Mono 대문자 (local() + 시스템 폴백)
- 상시 HUD: 크롭마크, "0N / 12 — 역할", "NVIDIA 1993→2026 · 120 BPM" + 4칸 박 인디케이터, 1993–2026 연도 눈금자, 씬별 출처 라인
- 질감: 그레인, 다크 씬의 회로 격자 점과 그 위를 흐르는 신호 펄스, 도면 격자, 방사형 글로우

# 기술 요구
- index.html + css/ + js/ 분할, classic script + 전역 SX 네임스페이스(file:// 동작)
- render(t) 순수 함수, 시드 고정 난수, window.seek(t) 노출
- 오디오: WebAudio로 120 BPM 트랙 생성, OfflineAudioContext로 같은 스케줄을 WAV 렌더
- 컨트롤: 재생/정지, 스크럽 바, 박 그리드 오버레이 토글
- tools/render.mjs: CDP로 t=i/FPS마다 seek→캡처, ffmpeg로 WAV와 합성해 MP4 출력
