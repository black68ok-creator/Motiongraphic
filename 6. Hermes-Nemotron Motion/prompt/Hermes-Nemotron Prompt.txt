# 역할
당신은 모션 디자이너 겸 크리에이티브 코더입니다. 첨부한 dataset/Hermes_Nemotron_Termux_Dataset.md로 25초 모션그래픽을 만듭니다. 슬라이드쇼나 설치 매뉴얼 나열이 아니라, 음악 박자에 맞춰 휴대폰·터미널·파일·채팅·시계 오브젝트가 변형·이동하며 "휴대폰 하나로 550B 모델을 무료로 부려 텔레그램으로 일을 맡긴다"를 한 문장으로 전달하는 영상이어야 합니다.

# 입력
- 주제: 안드로이드 Termux에 Hermes Agent를 설치하고, NVIDIA build 무료 API로 Nemotron 3 Ultra(550B)를 연결해 텔레그램 봇으로 AI 자동화하기
- 목적/타깃: 설정 과정을 한 번에 보여 주는 쇼케이스 / AI 에이전트·자동화에 관심 있는 한국어권 사용자
- 핵심 메시지: 550B짜리 AI를 내 휴대폰에서 직접 돌리면 B200 네 장이 필요하지만, API로 부르면 0원이다. 휴대폰에 Termux를 열고 Hermes Agent를 설치한 뒤 NVIDIA 키 하나로 네모트론을 연결하면, 550B 중 55B만 깨어 일한다. 텔레그램 봇을 하나 만들어 게이트웨이로 이어 붙이면, 말로 맡긴 일이 알아서 돈다. 주머니 속, 나만의 AI 비서.
- 데이터: 첨부 파일(유일한 소스)
- 마무리: "HERMES × NEMOTRON" 텍스트 타이틀 + 데이터 기준일
- 언어: 헤드라인은 한국어, 마이크로 라벨과 명령어는 영문

# 데이터 규칙
- 명령어·변수명·모델 ID는 파일에 적힌 그대로 씁니다. 키·토큰·사용자 ID는 반드시 가립니다(nvapi-•••, 123456:ABC-•••).
- 2차 출처뿐인 값(~40 RPM, 자체 호스팅 최소 사양, termux-wake-lock 팁)에는 "~" 또는 3RD-PARTY 라벨을 붙입니다.
- 크론 예시("매일 아침 8시에 뉴스 브리핑", 0 8 * * *)는 기능을 보여 주는 예시이므로 화면에 EXAMPLE을 붙입니다.
- 장식 HUD는 설정 단계(START → CRON), 씬 번호, 박 카운터만 씁니다.
- Telegram·NVIDIA·Nous Research 로고와 앱 UI를 재현하지 않습니다. 휴대폰과 채팅은 일반 도형으로 그립니다.

# 사양
- 1920×1080, 30fps, 25초, 120 BPM (1박 = 0.5초 = 15프레임)
- 1씬 = 4박(2초), 총 12씬. 12번 씬은 6박(3초)
- 시간 계층: 씬=4박 / 핵심 이벤트=1박 / 반복 사이클=16분음표 / 몽타주 컷=8분음표
- 전환은 박 3~5프레임 전에 시작해 박에 착지

# 데이터→비주얼 매핑
- 구성 요소 6개 → 알약 안 고속 사이클
- 550B → 휴대폰 화면 카운트업 / 550칸 그리드에 55칸 점등(MoE)
- 자체 호스팅 최소 사양 → GPU 보드 낙하
- 무료 엔드포인트·RPM → 브라우저 목업 + FREE 도장 + 게이지 바늘
- 설치 명령 → 터미널 타이핑
- [termux] 번들 6개 → 체크박스 + 형광펜
- 키·설정 → 파일 목업 + 키 카드 삽입
- 1M 컨텍스트 → 진행 바
- 텔레그램 봇 생성 → 채팅 말풍선
- 게이트웨이 → 노드 3개 사이 패킷 왕복
- 크론 → 시계 다이얼 + 기능 태그

# 씬 초안
01 HOOK | 다크 | "550B짜리 AI를 / 내 휴대폰에서," | 구성 요소 알약 사이클 → 휴대폰 화면 550B | 화면이 프레임 전체로 열림
02 PROBLEM | 페이퍼 | "직접 돌리면 / B200 네 장이 필요하지만," | GPU 보드 낙하 + MIN. SPEC 도장 | 휩 팬
03 FREE | 앰버 | "API로 부르면 / 0원이다." | 모델 페이지 목업, FREE 도장, RPM 게이지 | FREE 도장으로 아이리스 수축
04 TERMUX | 다크 | "휴대폰에 / Termux를 열고," | 원라인 설치 타이핑 | RGB 색수차
05 INSTALL | 블루 | "Hermes Agent를 / 설치한 뒤," | [termux] 번들 체크 6개 | 6줄 스트립 셔터
06 KEY | 페이퍼 | "NVIDIA 키 하나로 / 네모트론을 연결하면," | .env / config.yaml 목업, 키 카드 | 슬라이스 글리치
07 MODEL | 로즈 | "550B 중 55B만 / 깨어 일한다." | 550칸 중 55칸이 16분음표마다 바뀌어 점등, 1M 바 | 링 버스트
08 BOT | 블루 | "텔레그램 봇을 / 하나 만들어," | BotFather 채팅 말풍선 | 하드컷
09 GATEWAY | 다크 | "게이트웨이로 / 이어 붙이면," | 노드 3개 패킷 왕복 | API 노드에서 아이리스 팽창
10 AUTOMATION | 앰버 | "말로 맡긴 일이 / 알아서 돈다." | 요청 → cron → 시계 08:00 | 하드컷
11 MONTAGE | 5색 | (숫자만) | 8분음표 8컷 | 아이리스로 다크
12 END CARD | 다크 | "주머니 속, / 나만의 AI 비서." | 봇 채팅 예시 + 타이틀 | 마지막 1박 미세 모션

# 디자인 시스템
- 5색: 나이트 #0C0B10, 앰버 #FFB224, 블루 #2F6BFF, 페이퍼 #EEEBE4, 로즈 #F2557A (잉크 #121116)
- 타이포: Pretendard Black / JetBrains Mono (local() + 시스템 폴백)
- 상시 HUD: 크롭마크, "0N / 12 — 역할", BPM + 4칸 박 인디케이터, 설정 단계 눈금자(START → CRON), 씬별 출처
- 질감: 그레인, 다크 씬의 회로 격자 점 + 신호 펄스, 도면 격자
