# 역할
당신은 모션 디자이너 겸 크리에이티브 코더입니다. 첨부한 apollo-11_dataset_1969.md로 13초 데이터 모션그래픽 예시를 만듭니다. 슬라이드쇼나 인포그래픽 나열이 아니라, 음악 박자에 맞춰 로켓·궤적·착륙선·다이얼이 변형·이동하며 "8일의 왕복"을 한 문장으로 전달하는 영상이어야 합니다.

# 입력
- 주제: Apollo 11, 1969-07-16 발사 → 07-20 착륙 → 07-24 귀환
- 목적/타깃: 템플릿 사용법을 보여 주는 짧은 예시 작품 / 데이터 모션그래픽에 관심 있는 한국어권 시청자
- 핵심 메시지: 1969년 7월 16일, 110.6m 로켓이 솟아올라 38만 km를 날아 고요의 바다에 내렸고, 21시간 36분을 머문 뒤 8일 만에 돌아왔다.
- 데이터: 첨부 파일(유일한 소스)
- CTA: "APOLLO 11 · 1969" 텍스트 타이틀 + 데이터 정리일
- 브랜드 색/폰트: 비어 있음(직접 설계)
- 언어: 헤드라인은 한국어, 마이크로 라벨은 영문 대문자

# 데이터 규칙
- 모든 수치·날짜는 첨부 파일에서만 가져옵니다. 파일에 없는 값(속도, 연료 잔량 같은 텔레메트리)은 만들지 않습니다.
- 지구–달 거리는 평균값이므로 화면에 MEAN을 붙입니다.
- 공식 미션 패치와 기관 로고를 재현하지 않습니다. 로켓과 착륙선은 단순화한 일반 실루엣으로 그립니다.

# 사양
- 1920×1080, 30fps, 13초, 120 BPM (1박 = 0.5초 = 15프레임)
- 1씬 = 4박, 총 6씬. 6번 씬은 6박으로 남는 시간을 흡수합니다(총 26박 = 390프레임).
- 시간 계층: 씬=4박 / 핵심 이벤트=1박 / 반복 사이클=8분음표 카운트다운
- 전환은 박 4~5프레임 전에 시작해 박에 착지합니다.

# 데이터→비주얼 매핑
- 발사 일시(§1) → 카운트다운 다이얼(T−10 → T−00, 8분음표)
- Saturn V 높이·엔진(§3) → 높이 눈금자 + 카운터
- 지구–달 평균 거리(§4) → 궤적 아크 드로잉 + 카운터
- 착륙 일시(§1) → 박마다 감속하는 하강 + LANDED 도장
- 표면 체류·EVA·시료(§2) → 24시간 다이얼 링 + 칩
- 총 미션 시간(§2) → 미션 경과 시계 + 귀환 아크

# 씬 초안 (번호 역할 | 배경 | 카피 | 시그니처 모션 | 다음 씬 전환)
01 HOOK | 다크 | "1969년 / 7월 16일," | 카운트다운 다이얼 | 링 버스트
02 LAUNCH | 레드 | "110.6m 로켓이 / 솟아올라," | 박마다 솟는 로켓 + 높이 눈금자 | 플룸 기둥이 벌어지는 스트립 셔터
03 TRAVEL | 틸 | "38만 km를 / 날아" | 지구→달 궤적 드로잉 | 달이 팽창하는 아이리스(매치 컷: 달 → 지면)
04 LANDING | 페이퍼+도면 격자 | "고요의 바다에 / 내렸고," | 감속 하강 + 도장 | 슬라이스 글리치
05 SURFACE | 골드 | "21시간 36분을 / 머문 뒤," | 24시간 다이얼 스윕 | 다이얼 축 스핀 콜랩스
06 END CARD | 다크 | "8일 만에, / 돌아왔다." | 귀환 아크 + 미션 시계 + 착수 파문 | 마지막 1박 미세 모션만

# 디자인 시스템

- 헤드라인 Pretendard Black, 마이크로 라벨 JetBrains Mono 대문자, 숫자 tabular-nums
- 상시 HUD: 크롭마크, "0N / 06 — 역할", "APOLLO 11 · 1969 · 120 BPM" + 4칸 박 인디케이터, 하단 JUL 16–24 날짜 눈금자, 좌하단 데이터 출처
- 질감: 그레인, 별 필드(다크), 도트 격자(틸), 도면 격자(페이퍼), 방사형 글로우

# 모션 규칙 / 금지 / 기술 요구
